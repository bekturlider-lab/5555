# AI-поддержка B bank

AI-интеграция реализована на сервере. Настоящий провайдер не подключён автоматически: в архиве нет API-ключа, и по умолчанию AI_ENABLED=false. Обычные обращения и запрос человека работают без внешнего AI.

## Подключение на Render

В Environment веб-сервиса задайте:

```dotenv
AI_ENABLED=true
AI_API_FORMAT=gemini
AI_PROVIDER_LABEL=Google Gemini
AI_API_BASE_URL=https://generativelanguage.googleapis.com/v1beta
AI_API_KEY=YOUR_VALUE_HERE
AI_MODEL=gemini-2.5-flash-lite
AI_TOKEN_PARAMETER=max_tokens
AI_JSON_MODE=true
ORGANIZER_NAME=Имя или название организатора занятия
```

Ключ вводится только в серверные настройки Render или локальный .env. Не добавляйте его в GitHub, интерфейс, сообщения в поддержку или переменные VITE_*. Заголовок авторизации и структура запроса выбираются адаптером. Переходы по перенаправлениям и автоматические повторные запросы отключены.

Имя текстовой модели задаётся свободно в AI_MODEL: в коде нет фиксированного списка моделей. Поддерживаются четыре формата API. Пустой AI_API_BASE_URL автоматически выбирает стандартный адрес соответствующего формата, пустой AI_PROVIDER_LABEL — название по адресу. Для стороннего провайдера или посредника задайте адрес и название явно.

| AI_API_FORMAT | Назначение | Стандартный базовый адрес |
| --- | --- | --- |
| openai_chat | Chat Completions и совместимые сервисы | https://api.openai.com/v1 |
| openai_responses | OpenAI Responses | https://api.openai.com/v1 |
| anthropic | Claude Messages | https://api.anthropic.com/v1 |
| gemini | Gemini GenerateContent | https://generativelanguage.googleapis.com/v1beta |

Для Chat Completions моделей, которые требуют max_completion_tokens, задайте AI_TOKEN_PARAMETER=max_completion_tokens. Если текстовая модель не принимает параметр JSON-режима, установите AI_JSON_MODE=false: JSON всё равно запрашивается инструкцией и проверяется сервером. Некорректный ответ переводит вопрос человеку. Модели должны принимать текстовый диалог и возвращать текст; модели только для изображений, речи или эмбеддингов не подходят для этой поддержки. Для медленных reasoning-моделей может потребоваться больший лимит токенов; тайм-аут сервиса остаётся ограниченным.

Примеры базовых адресов из официальной документации:

| Провайдер | AI_API_BASE_URL |
| --- | --- |
| OpenAI | https://api.openai.com/v1 |
| Google Gemini, совместимый API | https://generativelanguage.googleapis.com/v1beta/openai |
| OpenRouter, совместимый API | https://openrouter.ai/api/v1 |

Идентификатор модели выбирает организатор из доступных его ключу моделей. Один ключ не становится ключом всех компаний: он действует у своего провайдера. Для нескольких семейств моделей с одним ключом можно использовать совместимый сервис-посредник, например OpenRouter, с AI_API_FORMAT=openai_chat. На таком сервисе имя модели обычно включает префикс организации. Доступ, квоты и цена определяются его условиями. Совместимость конкретной модели проверяется перед занятием; поддержка произвольного неизвестного протокола API не заявляется.

После сохранения настроек пересоберите или перезапустите сервис. Откройте поддержку, проверьте показанное название провайдера, отдельно разрешите отправку AI и задайте тестовый вопрос. При изменении имени организатора или названия провайдера меняется версия пакета соглашений, поэтому потребуется повторное подтверждение.

## Лимиты и расходы

По умолчанию: до 20 AI-запросов в час с одного IP, до 200 внешних запросов в сутки на приложение (суточный ключ по UTC), не более 600 выходных токенов и тайм-аут 15 секунд. Лимиты сохраняются в базе. AI_DAILY_BUDGET_REQUESTS ограничивает число запросов, а не денежную сумму. Счётчик квот не заменяет лимит расходов в кабинете провайдера. Бесплатный хостинг не делает внешний API бесплатным.

## Данные и поведение

- Передача внешней модели начинается только после отдельного согласия. До него можно запросить человека.
- Сохраняются до 20 последних сообщений чата; провайдеру уходят до 10 последних. Добавляется только справка об опубликованных функциях и продуктах.
- Профиль, сеансы, баланс и банковская история не включаются. Очистка похожих на пароли, API-ключи и длинные номера — дополнительная мера, не гарантия распознавания любых секретов.
- AI не получает инструменты банковских операций. Он не может переводить деньги, менять пароль, ограничивать клиента или выдавать коды.
- Телефоны берутся из SUPPORT_PHONE_PRIMARY и SUPPORT_PHONE_SECONDARY только при передаче человеку. Модель не получает эти номера и не выбирает их сама.
- Передача происходит по решению модели, при явном запросе человека, признаках захвата аккаунта, повторных неудачах, недоступности провайдера или некорректном ответе.
- Для вошедшего клиента создаётся одно обращение с очищенной перепиской; гостю показываются контакты. Автоматических звонков, писем и сообщений в WhatsApp нет.
- После начала передачи чат направляет к человеку. Чтобы задать другой вопрос AI, удалите этот чат и начните новый.
- Отзыв AI-согласия удаляет AI-чаты этого подтверждения, но не созданные отдельно обращения, банковские операции и аудит. Сайт не удаляет сообщения у внешнего провайдера.

Чаты старше семи дней удаляются при следующем AI-запросе. Для очистки без посетителей организатор запускает `python backend/scripts/cleanup_support.py`. Расписания в проекте нет. Полный сброс раунда также удаляет AI-чаты.

## Локальная настройка без вывода ключа

`python backend/scripts/configure_ai.py --provider gemini --model gemini-2.5-flash-lite`

Команда запросит ключ скрытым вводом и сохранит его в исключённый из Git файл .env с ограниченными правами. Другие переменные сохранятся. Для Render используйте Environment веб-сервиса; локальный .env не загружается с исходниками.

В текущем обновлении доступ к Google из рабочей среды не установлен (ошибка соединения). Это не подтверждает и не опровергает действительность переданного ключа. После развёртывания проверьте реальный ответ.

## Проверка реального ответа

После настройки .env запустите из корня проекта `python backend/scripts/check_ai.py`. Команда посылает синтетический вопрос, не выводит ключ и различает сетевую ошибку, HTTP-ошибку и непустой ответ. Это не заменяет проверку чата с согласием и правами. После изменений .env перезапустите сервер. `.env.example` не является рабочей конфигурацией.
