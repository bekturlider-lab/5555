# B bank · MODULAR, редакция 4

Выбран первый концепт: прямая B из двух округлых блоков, без засечек и перечёркиваний. Палитра #FFDD2D, #111111, #FFFFFF. Надпись bank переведена в контуры DejaVu Sans Bold; знак построен вручную. Все PNG экспортированы из SVG.

Исходник: design/rebuild_logos.py. Готовые файлы: frontend/public/brand-assets/. Пересборка требует CairoSVG и fontTools, для работы сайта они не нужны. Жест семи нажатий сохранён.
